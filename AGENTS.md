# Instructions for Agents

## Commit guidelines

- Use clear and descriptive commit messages.
- Create logical commits as you change code.
- Suffix the commit message subject (first line) with `[agent]` when you create a commit as an agent.
- Mark the commit as co-authored if you create or modify it as an agent, using the `Co-authored-by` trailer in the commit message.
- Specify files to commit explicitly when calling the commit command, so you don't accidentally commit unrelated changes.

## Documentation

- Update relevant README files or inline code comments to reflect the changes.
- Maintain clear and concise documentation for future reference.
- Do not add unnecessary or redundant documentation, such as repeating information that is already clear from the code itself.
- Do not use code comments to explain your thinking in the moment; code comments should be reserved for explaining the purpose and functionality of the code itself. Your explanations should go in the chat instead.
